## 3. Bugs critiques identifiés

### ✅ RÉSOLU — Migration 33→34

**Fichier** : `app/src/androidTest/java/com/forestry/counter/data/local/Migration33To34Test.kt` (lignes 42-54)

**Problème initial** : La migration ajoute `DEFAULT 1` sur la colonne `version` mais les entités Room ne déclaraient pas `@ColumnInfo(defaultValue = "1")`. Incohérence schéma → crash potentiel après migration.

**Statut** : **Déjà corrigé** dans le commit `4f42e62` (2026-08-03). Les 12 entités ont maintenant `@ColumnInfo(name = "version", defaultValue = "1")` et le schéma `34.json` a été régénéré.

**Nettoyage optionnel** : Le bloc FIXME stale dans `Migration33To34Test.kt:42-54` pourrait être retiré et `runMigrationsAndValidate` activé pour validation complète.

### ✅ RÉSOLU — Indice de station (approximation → IS officiel ONF)

**Fichier** : `app/src/main/java/com/forestry/counter/domain/calculation/ExpertForestryCalculator.kt` (lignes 162-204)

**Problème initial** : IS ≈ Hdom au lieu du calcul officiel ONF avec âge de référence (100 ans chêne, 80 ans hêtre, 50 ans résineux).

**Statut** : **Corrigé** dans le commit `3fd23a1` (2026-08-04). IS = Hdom × (âgeRéf / âgeActuel) si âge < âgeRéf, sinon IS = Hdom. 13 tests ajoutés (extrapolation, âge réf, essence inconnue, âge nul, bornes). 50 tests au total, tous passants.

### ✅ RÉSOLU — Certificate pinning

**Fichier** : `app/src/main/java/com/forestry/counter/network/SecureHttpClient.kt`

**Problème initial** : Pinning désactivé par choix architectural (crainte des rotations TLS).

**Statut** : **Corrigé** dans le commit `2361ec9` (2026-08-04). Pinning activé pour 8 domaines (7 carto + GSIE API dynamique) avec pin primaire + pin de secours pour chaque domaine. `network_security_config.xml` mis à jour. 4 tests ajoutés.

**⚠️ Point d'attention production** : Les pins sont des placeholders (`sha256/AAAA...`). À remplacer par les hashes SHA-256 réels avant mise en production.

### 🟡 MOYEN — BackupService non implémenté

**Fichier** : `app/src/main/java/com/forestry/counter/data/service/BackupService.kt` (lignes 18-23, 51-62)

**Problème** : `export()` et `import()` lèvent `NotImplementedError`. Tests `@Ignore`.

**Action** : Reporter au Lot 1 (pas bloquant pour Lot 0).
